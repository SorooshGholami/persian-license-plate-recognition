The classifier is trained on folder names, so it emits Latin tokens like PwD, Gh and Taxi. Persian letters, province and category are resolved after recognition — the network never has to learn Persian glyphs as text. Misordered output such as 1235373D is rejected rather than reassembled into a plate that would look valid but belong to a different car.
